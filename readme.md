### Как запустить проект Yacut:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone 
```

```
cd yacut
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Создать в директории проекта файл .env с четыремя переменными окружения:

```
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DB=sqlite:///db.sqlite3
```

Создать базу данных и применить миграции:

```
flask db upgrade
```

Запустить проект:

```
flask run
```

# YaCut - Сервис для сокращения ссылок и загрузки файлов

YaCut - это веб-сервис для создания коротких ссылок и загрузки файлов в облачное хранилище с генерацией коротких ссылок для доступа.

## Технологии

- **Backend:** Python 3.9+, Flask
- **База данных:** SQLite/PostgreSQL с SQLAlchemy ORM  
- **Асинхронность:** aiohttp для работы с API Яндекс.Диска
- **Фронтенд:** Jinja2, Bootstrap
- **API:** RESTful API с JSON форматом
- **Облачное хранилище:** Яндекс.Диск API

## Функциональность

- Создание коротких ссылок для длинных URL
- Возможность указать свой вариант короткой ссылки
- Загрузка файлов на Яндекс.Диск с получением коротких ссылок
- REST API для интеграции с другими приложениями
- Автоматическая генерация уникальных коротких идентификаторов
